# Form Service

Сервис для создания и публикации форм отклика на стажировки и мероприятия.

## Стек

- **Backend:** Node.js 20+, Express.js
- **Frontend:** HTML, Alpine.js, Tailwind CSS 4
- **Хранение данных:** локальный JSON (`data/db.json`)
- **API:** REST

## Возможности

- Создание форм с настраиваемыми полями
- Публикация форм по уникальной ссылке
- Отправка и просмотр ответов
- Статистика просмотров, заявок и конверсии

## Установка и запуск

Требуется Node.js 20+ и npm.

```bash
npm install
npm start
```

Приложение доступно по адресам:

- **Админка:** http://localhost:3000/admin
- **Публичная форма:** http://localhost:3000/f/:id

Порт можно изменить через переменную окружения:

```bash
PORT=8080 npm start
```

## Особенности

- Не требует внешней базы данных, API-ключей или облачных сервисов.
- Tailwind CSS собирается автоматически при `npm start`.
- Все данные хранятся локально в `data/db.json`.
- Авторизация в административной панели отсутствует по условиям тестового задания.
